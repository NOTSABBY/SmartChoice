# Evidence-Based NOVA Classification Methodology

## 1. Source Certainty Taxonomy
- `SOURCE_REPORTED`: External primary data (Open Food Facts / package declaration) with explicit external provenance disclaimer.
- `INTERNALLY_ESTIMATED`: Computed via multi-factor rule engine requiring >= 2 lines of evidence.
- `INSUFFICIENT_DATA`: Missing ingredients or inconclusive markers.

## 2. Prior-Only Rejection
Category priors are supporting context only. A product can never be assigned NOVA 4 based solely on category priors.
