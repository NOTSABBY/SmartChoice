# Data Completeness & Analysis Confidence Methodology

## 1. Decoupled Formulations
Completeness measures fact presence (0-100%). Confidence measures epistemic certainty (0.0-1.0) and basis verification.

- Completeness: 40% nutrition + 30% ingredients + 15% processing + 15% catalog.
- Confidence: 45% nutrition + 35% ingredients + 20% processing. Missing processing data depresses overall confidence, preventing artificial inflation.
